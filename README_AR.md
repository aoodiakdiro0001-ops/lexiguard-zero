# ‎ليكسِ‑غارد زيرو (Lexi-Guard Zero)

# ⚠️ إخلاء مسؤولية — ليست استشارة قانونية

**ليست استشارة قانونية.** يراجع ليكسِ‑غارد زيرو أنماط البنود الطُرُقية (الاستدلالية) بلغة عربية وإنجليزية، وهو مولّد إشارات أوّلي لأنسين بشري؛ **لا يُغني عن رأي محامٍ مرخَّص**، و كل تقرير يكرّر هذا التنبيه. راجع محامياً مؤهّلاً قبل أي اتفاق حقيقي.

---

## ما هو؟

أداةٌ محلّيةّ بالكامل (offline-first) لمراجعة العقود والمستندات وإبراز علامات الخطر، موجَّهة للمستقلّين والشركات الصغيرة. تقرأ الملفات (PDF/txt/md/html/rtf) **على جهازك**، وتقسّمها إلى بنود، وتقارنها بنحو ٢٠ قاعدة كشف ثنائية اللغة، ثم تُصدر درجةً واضحة وشفّافة، وتُنتج تقارير Markdown/HTML/JSON تتضمّن **قوالب بنود بديلة** عادلة.

## حدود الأداتة الصادقة — اقرأها أولاً

- **مُولّد إشارات لا مُحكِم.** يعرف المحرّك الأنماط المُعرَّفة في قواعده فقط (`lexiguard/rules.py` — ٢٠ قاعدة). الصياغات غير المعتادة قد تخفي نفس المخاطر، والصياغات البسيطة قد تبدو خطرة؛ وقد يفوّت أو يُضخّم النتائج.
- **غياب المؤشرات ليس «عقداً آمناً».** أدنى شُرُح يُسمّى حرفياً `none` — «لم تُكتشف أنماط معروفة» — ولا يُقدَّم يوماً كتصفية أو اعتماد أو ضمانة سلامة قانونية.
- **لا قراءة زائفة للصور.** ملفات PDF الممسوحة ضوئياً (بلا نصّ) تُكتشف وتُبلَّغ بصدق: «شغّل أولاً `ocrmypdf` أو Tesseract». لا تتنكّر الأداة أبداً في قراءة نصّ لم تستخرجه فعلاً.
- **نص البند البديل قالبٌ** يُكيَّفه الإنسان — القيم المعقوصة مثل `[30]` يوماً أو `[5]%` **واجبة الملء**، وليس ضمانة قانونية، وقد لا يناسب نظام بلدك.
- **لا ادّعاءات بدقة مئوية.** درجات الخطورة إشارات تفاوضية لا حُجّية في النفاذ.
- **العقود سرّية.** تجري المعالجة كاملةً على جهازك، ولا توجد أيّ مُسبِّبات لُقُوم (telemetry). طبقة الذكاء الاصطناعي والإشعارات **مطفأة افتراضياً** وما ترسله محدود بدقة (انظر [docs/PRIVACY.md](docs/PRIVACY.md)).

## كيف تعمل؟

```
استخراج ← تقطيع إلى بنود ← مطابقة القواعد ← احتساب الدرجة ← التقرير
(محليّاً)   (ترويسات مرقّمة      (٢٠ نمطاً        (شرُح شفّافة،    (md/html/json +
 أو فقرات)   ثنائية اللغة)         بلا «آمن»)       قوالب بنود)
```

التفاصيل: [docs/HOW_IT_WORKS.md](docs/HOW_IT_WORKS.md).

### الصيغ المدعومة

| الصيغة | المحرك | ملاحظات |
|---|---|---|
| `.txt` `.md` `.markdown` `.csv` `.json` `.text` | المكتبة القياسية | تعمل دائماً، بلا تبعيات |
| `.html` `.htm` | محلّل قياسي | وسم `<script>` يُ **نصّ يُستخرج** لا يُنفَّذ |
| `.rtf` | المكتبة القياسية | استخلاص مبسّط لرموز التحكم |
| `.pdf` | PyMuPDF أو pdfplumber (اختياري) | دونهما تظهر رسالة صادقة تقترح التحويل؛ والPDF الممسوح ضوئياً → خطأ صريح «شغّل OCR أولاً» |

تُحدَّد قراءة الملفات عند **٥ ميغابايت** والـPDF عند **٢٠٠ صفحة** (ضوابط ضدّ الملفات الخبيثة، انظر [SECURITY.md](SECURITY.md)).

## التثبيت

يتطلّب Python 3.8+، ولا تبعيات إلزامية للمحرّك.

```bash
# الخيار أ — دون تثبيت، من مجلّد المستودع:
python -m lexiguard --help

# الخيار ب — تثبيت تطويري (يوفّر الأمر lexiguard):
pip install -e .
lexiguard --help
```

لدعم PDF، ثبّت محرّكاً اختيارياً مجانياً (غير لازم لبقية الصيغ):

```bash
pip install PyMuPDF        # أو: pip install pdfplumber
```

وافحص بيئتك في أي وقت:

```bash
python -m lexiguard doctor
```

## البدء السريع

بالنماذج المضمَّنة في `examples/`:

```bash
# عقد إنجليزي خطر عمداً — توقّع شرحاً عاجلاً
python -m lexiguard scan examples/sample-risky-en.txt

# عقد عربي خطر عمداً — نفس المحرّك بالأنماط العربية
python -m lexiguard scan examples/sample-risky-ar.txt

# نموذج متوازن من زاوية مقدّم الخدمة
python -m lexiguard scan examples/sample-fair-en.txt --side provider

# تقرير HTML كامل بالقوالب
python -m lexiguard report examples/sample-risky-en.txt -f html -o review-ar.html

# تقرير JSON للآلة
python -m lexiguard report examples/sample-risky-ar.txt -f json -o review.json

# بوابة للأنظمة: رمز خروج ٢ عند بلوغ خطورة «high»
python -m lexiguard scan examples/sample-risky-en.txt --fail-on high
```

### الأوامر

| الأمر | الغرض | أعلام إضافية |
|---|---|---|
| `scan FILE` | مراجعة سريعة في الطرفية | `--side`، `--ignore RULE_ID` (يُكرَّر)، `--min-severity`، `--fail-on low\|medium\|high`، `--notify` (تيليغرام، اختياري)، `--ai gemini`، `--deal-hint`، `--config` |
| `report FILE` | كتابة تقرير كامل | `-f/--format markdown\|html\|json`، `-o/--output`، `--side`، `--config`، `--ai gemini`، `--deal-hint` |
| `doctor` | فحص بايثون والمحرّكات الاختيارية والإعدادات ومتغيّرات البيئة | `--config` |

أعلام مشتركة: `--config PATH` و`--side provider|client|both`.
رموز الخروج: `0` نجاح · `1` خطأ · `2` (بلوغ حدّ `--fail-on`) · `130` مقاطعة.

## الإعداد — `.lexiguard.json`

اختياريّ. يُبحث عنه في مجلّد العمل باسم `.lexiguard.json` (أو `lexiguard.json`)، أو حدّد ملفاً بـ`--config`. جميع المفاتيح اختيارية، وأعلام الطرفية تُرجَّح فوق الملف، و`--ignore` تُضيف إلى قائمته.

```json
{
  "ignore_rules": ["LG-SETTLE-DISTANT-FORUM"],
  "min_severity": "low",
  "side": "provider"
}
```

| المفتاح | القيم | الأثر |
|---|---|---|
| `ignore_rules` | معرّفات قواعد | تجاوز هذه القواعد كلياً |
| `min_severity` | `info` \| `low` \| `medium` \| `high` | أرضية للخطورة — تُخفى ما دونها |
| `side` | `provider` \| `client` \| `both` | تُبقي القواعد المناسبة لزاويتك: `provider` مقدّم الخدمة/المستقل، `client` المشتري |

الملف المكسور **خطأ برسالة واضحة** لا تجاهُل صامتاً، وهو مُدرَج في `.gitignore`.

## الاحتساب — شفّاف وقابل للتدقيق

كل مؤشر يضيف نقاطاً ثابتة، والحساب مطبوع في كل تقرير:

| الخطورة | النقاط |
|---|---|
| high (عالية) | ٥ |
| medium (متوسطة) | ٢ |
| low (منخفضة) | ١ |
| info | ٠ (محجوزة) |

| مجموع النقاط | الشرحة | المعنى |
|---|---|---|
| ١٢ فأكثر | **urgent (عاجل)** | بنود عالية الإشارة تحتاج مراجعة قبل التوقيع |
| ٥–١١ | **review (مراجعة)** | بنود تستحق التفاوض |
| ١–٤ | **watch (مراقبة)** | إشارات أقلّ أثراً |
| ٠ | **none** | لم تُكتشف أنماط معروفة — **لا يعني ذلك عقداً آمناً** |

الشرحة إشارة ترتيب أولويات لإنسين، لا أكثر.

## فهرس القواعد (٢٠ قاعدة، ثنائية اللغة)

عمود «الزاوية» = الطرف الذي يضرّه النمط عادةً: `provider` (تبيع العمل)، `client` (تشتريه)، `both` (كلا الطرفين).

| المعرّف | الخطورة | التصنيف | الزاوية | ما يكشفه |
|---|---|---|---|---|
| LG-IP-PREPAY | high | ip | provider | انتقال ملكية الفكر في المخرجات قبل الدفعة أو دون ربطها بها |
| LG-NO-OWNERSHIP | high | ip | client | العميل يدفع ولا يكتسب أي حقّ في العمل |
| LG-UNILATERAL-TERM | high | exit | provider | حق إنهاء منفرد للعميل دون حقّ مماثل للمقدّم |
| LG-PERSONAL-GUARANTEE | high | liability | both | ضمان شخصي أو مسؤولية تضامنية لصاحب العمل |
| LG-UNLIMITED-LIABILITY | high | liability | both | مسؤولية غير محدودة لأحد الطرفين أو للطرفين |
| LG-ONEWAY-INDEMNITY | high | liability | provider | تعويض من طرف واحد في مصلحة العميل فقط |
| LG-LATE-PENALTY | medium | money | both | غرامة تأخير يومية أو بلا سقف |
| LG-COMPOUND-INTEREST | medium | money | both | فائدة مركّبة على المتأخرات |
| LG-PAY-NET90 | medium | money | provider | نافذة دفع طويلة جداً (٦٠/٩٠/١٢٠ يوماً فأكثر) |
| LG-NONREFUNDABLE | medium | money | client | جميع المبالغ غير قابلة للاسترداد مهما كان التسليم |
| LG-FINAL-PAY-SUBJECTIVE | medium | money | provider | ربط الدفعة الأخيرة بقناعة العميل الذاتية |
| LG-UNILATERAL-AMEND | medium | exit | both | إمكانية تعديل العقد من طرف واحد |
| LG-UNLIMITED-REVISIONS | medium | scope | provider | تعديلات غير محدودة دون نطاق محدّد |
| LG-NONCOMPETE | medium | scope | provider | منع واسع للمنافسة يقيّد أعمالك الأخرى |
| LG-MORAL-RIGHTS | medium | ip | provider | تنازل شامل عن الحقوق المعنوية |
| LG-DEPOSIT-FULL | medium | money | client | اشتراط دفع كامل المبلغ مقدّماً |
| LG-AUTORENEW | low | money | both | تجديد تلقائي دون نافذة إخطار |
| LG-EXCLUSIVE | low | scope | provider | تعاقد حصري دون ضمان حدّ أدنى للأجور |
| LG-SETTLE-DISTANT-FORUM | low | exit | both | اختصاص محكمة بعيدة أو قانون أجنبي |
| LG-CONF-INDEFINITE | low | data | both | التزامات سرّية بلا نهاية |

كل قاعدة تأتي بشرح بلغة واضحة وبقالب بند بديل ثنائي اللغة في التقارير؛ وقوالبها تتضمّن خانات معقوصة `[30]` و`[X]%` و`[الدولة]` **تُملأ من قبلك** ومع محاميك.

## طبقة الذكاء الاصطناعي الاختيارية (مطفأة افتراضياً)

يمكن لـGemini (المستوى المجاني) إعادة صياغة قالب البند البديل بما يناسب صيغة صفقتك. القوالب المحلية متاحة دائماً وهي الافتراض.

```bash
export GEMINI_API_KEY="مفتاحك"       # من Google AI Studio (مجاني)
python -m lexiguard report contract.pdf --ai gemini --deal-hint "تصميم شعار، ثابت"
```

**ما ترسله: قالب البند البديل للمؤشّر فقط** (بحدّ أقصى ١٢٠٠ حرف) مع سطر سياق صفقة اختياري وتعليمات نظام ثابتة — **ولا أبداً** المستند أو المقتطفات أو النتائج أو اسم الملف. أيّ عطل يُسقط تلقائياً إلى القالب المحلي، والتقرير يُعلِّم النصوص المعاد صياغتها. الملصق الكامل: [docs/PRIVACY.md](docs/PRIVACY.md).

## إشعارات تيليغرام الاختيارية (مطفأة افتراضياً)

أرسل تلميحاً **ملخّصياً فقط** إلى محادثة تيليغرام تملكها — معرّفات القواعد والعدادات، لا نصّ العقد:

```bash
export TELEGRAM_BOT_TOKEN="123:abc…"
export TELEGRAM_CHAT_ID="123456789"
python -m lexiguard scan contract.pdf --notify
```

دليل الإعداد: [docs/TELEGRAM_SETUP.md](docs/TELEGRAM_SETUP.md). الضمانة: المحتوى الشُحنة هو الشرحة والدرجة والعدادات ومعرّفات القواعد وإخلاء المسؤولية فقط — بلا نصّ المستند أو مقتطفات أو أسماء ملفات؛ وأيّ عطل لا يُفشل المسح، بل تظهر حالة `skipped`/`error` فقط.
